# Tacos Don Omar

Sitio web de un puesto de comida urbana mexicana ubicado afuera del acceso principal del CECyTEM Plantel Ecatepec 2.

> "¡El sazón que te hace volver!"

## Bienvenida

Disfruta tacos al pastor, suadero y bistec, además de gringas, quesadillas y aguas frescas, preparados con buen sazón e higiene.

**Horario:** lunes a viernes, de 10:00 a. m. a 8:00 p. m.

## Simulador de pedido

La página incluye un formulario para simular un pedido anticipado. Solicita nombre, teléfono o WhatsApp y tipo de cliente (estudiante, docente o público general). Permite indicar cantidades de tacos al pastor, tacos de suadero y gringas; elegir horchata, jamaica, limón o ninguna bebida; seleccionar cebolla y cilantro, piña y salsas roja o verde; y agregar indicaciones especiales. El formulario también permite enviar o borrar los datos.
